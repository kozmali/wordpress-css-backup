== Description ==
Automatic and manual backups for WordPress Additional CSS with restore and download support. This plugin helps you keep track of your custom CSS changes.

== Installation ==
1. Upload the plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to Appearance > CSS Backups to manage your backups.
